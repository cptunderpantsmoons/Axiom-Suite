# Decision Records

Intentional ContextLock behavior changes must add a decision record here.

Use this filename pattern:

```txt
YYYY-MM-DD-short-title.md
```

Each record should include:

- context/problem,
- decision,
- alternatives considered,
- compatibility impact,
- migration plan,
- rollback plan.

If a behavior change has no decision record, treat it as possible spec drift.
